# Demo samples

Five clips shipped with the repo so `Launch Demo.cmd` / `demo.py` works after a fresh clone **without** downloading full datasets.

| File | What it is |
|---|---|
| `world_cup_final.mp4` | Broadcast excerpt — Argentina vs France World Cup final |
| `casfd_foul_105.mp4` | CAS-FD test foul clip |
| `casfd_foul_128.mp4` | CAS-FD test foul clip |
| `casfd_foul_107.mp4` | CAS-FD test foul clip |
| `casfd_dive_101.mp4` | CAS-FD test dive clip (contrast case) |

Select any of these from the demo dropdown and click **Run analysis**.

Full training datasets remain separate — see [`../datasets/README.md`](../datasets/README.md).
